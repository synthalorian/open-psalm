# open-psalm

**"The Word, blazing fast in your terminal."**

## Vision
A TUI (Terminal User Interface) Bible reader designed for Arch Linux and Ghostty. High-performance scripture access without leaving the development environment.

## Tech Stack
- **Language:** C++ 20 / Rust
- **Interface:** TUI (using `ftxui` or similar)
- **Data:** SQLite / JSON (supports multiple translations: KJV, NKJV, ESV)

## Core Features
- **Vim Bindings:** Navigate the Word like you navigate your code.
- **Neon Themes:** Customizable color schemes (Sunset, Chrome, Matrix).
- **Deep Search:** Blazing fast indexing for word or phrase searches.
- **Ghostty Optimized:** Full support for Ghostty's modern terminal features.
